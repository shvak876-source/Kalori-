# קלורי

אפליקציית מעקב קלוריות וחלבון. עובדת בטלפון בתור אפליקציית ווב (PWA): בלי שרת, כל הנתונים נשמרים בטלפון עצמו.

## מה יש בה
- **הגדרה ראשונית**: גיל, מין, גובה, משקל, רמת פעילות ומטרה. מתוכם מחושבים יעד קלוריות (Mifflin‑St Jeor) ויעד חלבון.
- **היום**: כמה קלוריות נשארו, כמה חלבון אכלתם, ושורת "הוספה בלחיצה" עם המוצרים שאתם אוכלים הכי הרבה.
- **כפתור + גדול**: בוחרים מהמוצרים השמורים בלחיצה אחת, או מוסיפים אוכל **חד‑פעמי** (מספיק לכתוב רק כמה קלוריות).
- **סריקת תווית**: מצלמים את טבלת הערכים התזונתיים, והאפליקציה מזהה קלוריות, חלבון, פחמימות, סוכרים, שומן, שומן רווי, סיבים ונתרן. ערך שלא זוהה מסומן ב"להשלים". כותבים כמה גרם אכלתם ומקבלים את כל הערכים לכמות הזאת. הזיהוי (Tesseract.js) רץ בטלפון עצמו, ובפעם הראשונה הוא מוריד כ‑5MB.
- **סריקת ברקוד**: המצלמה מזהה את הברקוד לבד, והמוצר נשלף מהמאגר החינמי Open Food Facts, בלי מפתח. מוצר שנשמר עם ברקוד נכנס מהסריקה הבאה מיד ליומן, גם בלי אינטרנט. ברקוד שלא נמצא במאגר: מצלמים את התווית פעם אחת, והמוצר נשמר עם הברקוד.
- **סריקה חכמה עם AI (חינם)**: בלשונית "יעדים" אפשר לחבר מפתח חינמי של Google Gemini, של Groq או של שניהם. הסדר הוא Gemini, אחריו Groq, ואחריו הסורק הרגיל, כך שאם המכסה של שירות אחד נגמרת, האפליקציה עוברת לבא בתור.
- **ביומן**: לחצני +/− לשינוי כמות, ולחיצה על הכמות לעריכה מדויקת.
- **מוצרים**: עם תמונה, לפי יחידה או לפי 100 גרם, וכמות ברירת מחדל.
- **היסטוריה**: ממוצע של 7 ימים, הוספה חוזרת של פריט מיום קודם, והעתקת יום שלם.
- **חיבור ליומן האימון** ([automatic-guacamole](https://github.com/shvak876-source/automatic-guacamole)): כששתי האפליקציות פתוחות מאותו אתר GitHub Pages ‏(`shvak876-source.github.io`), הנתונים שלהן משותפים. במסך הבית רואים את האימון של היום ובערך כמה קלוריות נשרפו (הערכה בלבד, שלא נוספת ליעד), ובהיסטוריה רואים אימונים ליד האוכל. קלורי רק קורא את נתוני האימון ואף פעם לא משנה אותם.
- **גיבוי**: שמירה וטעינה של קובץ JSON.

## התקנה באייפון
1. מפעילים GitHub Pages ל‑repo: ‏Settings → Pages → Branch: `main`, תיקייה: `/ (root)`.
2. פותחים את הכתובת ב‑Safari, לוחצים על שיתוף ואז "הוספה למסך הבית".
